### 2. **Resume Analyzer Section** 📄

**File**: `src/app/screen/ResumeAnalyzerSection.tsx`

**What it does:**

- Interactive drag-and-drop PDF upload
- Real-time file validation
- Loading states with spinner
- Instant AI analysis preview
- Modal with detailed results

**Features:**

- Drag-and-drop zone with visual feedback
- File type validation (PDF only)
- Size limit (10MB)
- Beautiful loading animation
- Success state with file name
- 3 feature highlights below upload area

**User Flow:**

1. User drags PDF or clicks to browse
2. File uploads with visual feedback
3. AI analyzes (2s simulation)
4. Modal shows detailed results
5. User can upload another file
