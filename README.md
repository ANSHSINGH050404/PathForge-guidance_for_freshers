# PathForge-guidance_for_freshers

PathForge — career and learning guidance for freshers entering tech.

## Stack

Next.js, Drizzle, TypeScript

## Getting started

```bash
git clone https://github.com/ANSHSINGH050404/PathForge-guidance_for_freshers.git
cd PathForge-guidance_for_freshers
npm install
npm run dev   # or: npm start
```
